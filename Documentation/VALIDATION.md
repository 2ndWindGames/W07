# 검증 기록

검증일: 2026-09-11. Unity 6000.3.23f1 / Windows 개발 환경.

## 통과한 검사

- `RunBeatChecks.Run`: 258개. 목표 범위, 박자 간격, 시간 표기, 손상된 설정 파일의 백업 복구, 음악 목록, 폰트, 세로 화면과 W05 스플래시 설정.
- `Tools/Test-Native.ps1`: 91,816개 assertion. Android에서 사용하는 RhythmSynth 원본을 컴파일해 12개 목표·박자 간격 조합의 30분 분량 PCM을 합성. 모든 박자 위치 오차 0.5샘플 이내. 180 SPM·매 걸음은 5,400박.
- `RunBeatVisualQA`: 390×844, 360×640에서 실제 버튼 콜백, 3초 준비, 재생, 일시정지 시간 정지, 재개, 목표 구간 추가, 종료와 기록 저장.
- 두 해상도의 홈·음악·기록·설정·사운드·운동·일시정지·결과 화면을 렌더링해 확인. 운동 타이머와 하단 제어 버튼이 화면 안에 있는지 코드로도 검사.

검사 로그와 화면은 `BuildArtifacts/QA`에 저장됩니다. 이 디렉터리는 배포 앱과 버전 관리에 포함하지 않습니다. 에디터에서 생성한 짧은 테스트 운동은 실제 사용자 운동 기록이 아닙니다.

## APK 재검증

`Tools/Verify-Apk.ps1`은 실제 APK의 서명과 패키지 정보, 권한, 화면 방향, 네이티브 서비스 선언, ARM64 네이티브 라이브러리, ZIP 및 ELF의 16 KB 정렬을 검사합니다. 결과는 `BuildArtifacts/QA/APK`에 기록합니다. 설치용 APK와 게시자 키로 서명한 스토어 배포본을 구분해야 합니다.

2026-09-11 최종 APK 빌드 성공: 오류 0개. `Builds/Android/RunBeat-1.0.0.apk`, 45,522,588바이트. 위 APK 검사 모두 통과. 런처는 portrait, 서비스는 exported=false, 인터넷 권한은 포함하지 않습니다. 4개 ARM64 라이브러리의 모든 LOAD 세그먼트가 16 KB 이상 정렬되었습니다. 로컬 Android Debug 키 서명입니다.

SHA-256: `637CB5CA9ED8E020A439834E4BFBA31F76E1D7E628F397268B9494A80CAA5B4C`

## 아직 검증하지 않은 환경

이 개발 환경에는 adb로 연결된 Android 기기가 없습니다. 위 PCM 합성 검사는 실제 기기의 오디오 출력·장시간 재생 시험을 대체하지 않습니다. 전화·Bluetooth·화면 잠금·배터리 절약 모드와 실제 알림 제어는 [배포 체크 항목](RELEASE.md)에 따라 기기에서 검증해야 합니다.

## 이 개발 PC의 캐시 위치

C드라이브 공간 부족으로 W07의 `Library/Bee`만 `D:/CodexBuildCache/W07-RunBeat-01a08d85/Bee`로 옮기고 원래 위치에 디렉터리 junction을 만들었습니다. 프로젝트 소스와 리소스, APK 출력은 W07 안에 있습니다. Library는 Unity가 다시 생성할 수 있는 로컬 캐시이며 다른 PC의 프로젝트 실행에 이 D드라이브 경로가 필요하지 않습니다.
