# RunBeat resources

The user supplied `Mobile_Apps_Planning_with_UI_v1.0.pptx`. Slides 5–13 define RunBeat. The app follows slide 6's charcoal, lime, rounded controls, large cadence number, circular running dial, and illustrated music covers. The original phone screenshot is a reference, not a flattened application screen.

`Assets/RunBeat/Branding/SecondWindGamesLogo.png` and its sprite metadata are copied unchanged from `C:/SecondWindGames/Repositoires/Go/W05/Assets/Cozy/Branding/Splash/`. Splash settings match W05: white background, static logo, 2 seconds, Unity logo hidden.

`Assets/RunBeat/Resources/RunBeat/NotoSansKR.otf` is Noto Sans CJK KR Regular copied from W05. Its SIL Open Font License accompanies it as `Font-LICENSE.txt`, and is accessible in the app. UI icons are application-owned geometry. The three metronome timbres are generated from original deterministic waveforms in the native and desktop engines; no third-party audio is bundled.

`NotoSans-Black.ttf` provides the large cadence and timer numerals. It and `NotoSans-LICENSE.txt` were downloaded from the [official Noto font repository](https://github.com/notofonts/noto-fonts/tree/main/hinted/ttf/NotoSans), under SIL OFL 1.1. It is used unchanged.

The following artwork was generated with the built-in image generation tool on 2026-09-11 and copied into this project. It is decorative RunBeat artwork, not a YouTube thumbnail. Music is opened on YouTube; its audio and imagery are not downloaded or redistributed.
